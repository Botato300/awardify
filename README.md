# Awardify
A platform that lets you create your own awards, configure categories, add nominees, collect votes, and reveal the winners.

## How to run
You need to have **NodeJS** and **pnpm** installed. Run these commands in your terminal:

1. Install dependencies:
```bash 
pnpm install --frozen-lockfile
```

2. Run the server:
```bash
pnpm dev
```
